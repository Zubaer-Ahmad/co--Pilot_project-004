# Cove House

A full-stack boutique hotel booking desk built with React, Vite, Express, and a demo data store. Guests can browse rooms, filter by capacity, register or sign in, and create reservations through the API. The operations strip shows live summary data from the same backend.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. The API runs on `http://localhost:5004`.

The included demo account is `maya@example.com` / `demo-password`. Copy `.env.example` to `.env` to configure a different port, JWT secret, or MongoDB connection.
